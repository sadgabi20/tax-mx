# ROADMAP `tax-mx`

`tax-mx` se encuentra en etapa prerelease, lo cual la hace inestable y sujeta a cambios drásticos (braking changes).

Su desarrollo actual se centrará en lograr concretar una API y especificaciones estables antes de agregar nuevas características.

Las características planeadas a agregar en iteraciones más estables son:

- [ ] Añadir otros regímenes fiscales (RESICO, RIF, sueldos y salarios, etc.)
- [ ] Añadir miscelánea fiscal (deducciones, créditos fiscales, subsidios)
- [ ] Generar una librería Python de forma paralela (monorepo)
- [ ] Desplegar sitio web con documentación interactiva
